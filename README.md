# Abdul Al Jubayer — Premium 3D Portfolio & Link-in-Bio Creator Platform

A luxury dark-themed personal portfolio and next-generation 3D Link-in-Bio SaaS platform built with Next.js 14 App Router, Three.js, React Three Fiber, Framer Motion, and Tailwind CSS.

## 🌟 Key Features
- **3D Interactive Hero Canvas:** Real-time geometric sculpture with mouse tilt parallax & performance-optimized particle field.
- **Featured Live Web Projects:** Showcase real-world web applications with high-resolution domain branding, status badges, and click analytics.
- **Solid Realistic Profile Cards:** High-conversion profile card with panoramic cover banner, avatar with glowing bezel, status pill, and instant QR VIP Pass modal (no dead gaps).
- **1-Tap Direct WhatsApp Instant Chat:** Connect with visitors directly via pre-typed greeting messages without saving phone numbers.
- **3D Link-in-Bio Builder:** Multi-user creator platform with custom themes, bento grid & classic layouts, photo showcase, secret message box, and music player.
- **Admin Control Center:** Manage featured web projects, reviews, creator accounts, and site analytics.
